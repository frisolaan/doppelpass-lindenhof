# Doppelpass · Sportschule Lindenhof Wil (Prototyp)

Klickbarer Prototyp als Gesprächsgrundlage: Sportschüler:innen halten Szenen aus Training, Wettkampf und Schule fest, analysieren sie in vier Phasen (Situation, Entscheidung, Wirkung, Transfer) und machen so Skills neben dem Unterricht sichtbar.

- Rollenwechsler: Sportschüler:in, Lernbegleitung, Trainer:in, Eltern, Lehrbetrieb (Freigabelink), Fachkommission, Administration
- Keine Punkte, keine Leistungs- oder Gesundheitsdaten, privat als Standard
- **Konzeptstudie mit frei erfundenen Daten**, keine offizielle Anwendung der Oberstufe Lindenhof. Keine KI: Vorschläge sind vorformuliert. Daten bleiben im Browser (localStorage).

Statisch: `index.html` + `daten.js`, Deployment über Vercel.
